# RFC 2217

`@henglosio/rfc2217`

Talks to a serial port over the network.

## What it does

Implements RFC 2217, the standard way of reaching a serial (USB) port through a network connection.

## Where it fits

It lets a build container reach a board plugged into the computer, as if the board were plugged into the container.
