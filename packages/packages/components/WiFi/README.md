# WiFi

`@henglosio/component-wifi` — a Henglos IO component.

Puts the board on a Wi-Fi network — or makes it one.

## What it can do

- **Connect / Disconnect** — joins or leaves a network.
- **Status** — tells whether the board is connected.
- **Scan** — lists the networks around.
- **Access Point** — makes the board a network of its own, for phones and other boards to join.

> Needs a board with Wi-Fi, like the ESP32.

## Getting it

Add it to a workflow from the studio's library — search for **WiFi**.
