# Servo

`@henglosio/component-servo` — a Henglos IO component.

Moves hobby servo motors.

## What it can do

- **To Angle** — turns a regular servo (like the SG90) to an angle between 0 and 180° and holds it there.
- **Rotate** — spins a 360° servo at a speed, in either direction.
- **Release** — lets go of the servo.

## Getting it

Add it to a workflow from the studio's library — search for **Servo**.
