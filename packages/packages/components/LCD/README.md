# LCD

`@henglosio/component-lcd` — a Henglos IO component.

Shows text on a 16x2 or 20x4 character display.

## What it can do

- **Print** — writes text — or a reading — on a line.
- **Clear** — blanks the display, or one line.
- **Backlight** — turns the light on or off.

> Works with the common I2C module (4 wires) or wired straight to the board.

## Getting it

Add it to a workflow from the studio's library — search for **LCD**.
