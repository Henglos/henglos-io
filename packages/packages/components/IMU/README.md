# IMU

`@henglosio/component-imu` — a Henglos IO component.

Motion and tilt, from an accelerometer + gyroscope like the MPU-6050.

## What it can do

- **Read** — acceleration, rotation and temperature.
- **Orientation** — how the sensor is tilted, front to back and side to side.
- **Tilt** — goes Forward, Back, Left, Right or Level.
- **Motion** — goes Still, Moving or Falling.
- **Calibrate** — zeroes the sensor while it rests.

## Getting it

Add it to a workflow from the studio's library — search for **IMU**.
