# IR

`@henglosio/component-ir` — a Henglos IO component.

Infrared remote controls, both ways — act as a remote, or listen to one.

## What it can do

- **Send** — sends a button press from an IR LED — to a TV, an air conditioner, another board.
- **Receive** — reads which button a remote sent.
- **Match** — goes one way when a given button is pressed.

## Triggers

- **Code Trigger** — runs a branch when a given button is pressed.

## Getting it

Add it to a workflow from the studio's library — search for **IR**.
