# Sound Sensor

`@henglosio/component-soundsensor` — a Henglos IO component.

Listens for noise with a small microphone module (KY-037, KY-038 and the like).

## What it can do

- **Read** — how loud it is.
- **Detect** — goes one way when it is loud, another when it is quiet.

## Triggers

- **Sound Trigger** — runs a branch on a sound — a clap, a knock.

## Getting it

Add it to a workflow from the studio's library — search for **Sound Sensor**.
