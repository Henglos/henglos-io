# Filesystem

`@henglosio/component-filesystem` — a Henglos IO component.

The board's own files — to keep data between runs, write a log, or use what a web request saved.

## What it can do

- **Read / Write** — reads a file, or writes (or adds) to one.
- **Copy / Move / Delete** — organizes files and folders.
- **Info / List** — checks whether something is there, and what a folder holds.

## Getting it

Add it to a workflow from the studio's library — search for **Filesystem**.
