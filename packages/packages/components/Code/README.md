# Code

`@henglosio/component-code` — a Henglos IO component.

Runs a short Python script on the board — for the bits of logic no other block covers.

## What it can do

- **Run** — reads what earlier actions produced, does a calculation, and passes the result on.

> Scripts are kept short for now (64 bytes).

## Getting it

Add it to a workflow from the studio's library — search for **Code**.
