# Serial

`@henglosio/component-serial` — a Henglos IO component.

Lets two boards talk to each other over a serial wire.

## What it can do

- **Begin / End** — opens and closes the link.
- **Send** — sends a message to the other board.
- **Receive** — waits for a message from it.

> Wiring: TX to RX, RX to TX, and a shared GND.

## Getting it

Add it to a workflow from the studio's library — search for **Serial**.
