# Workflow

`@henglosio/workflow`

What a workflow is — its actions, wires, triggers and variables — and how it changes.

## What it does

- Defines the shape of a workflow and checks it's valid.
- Applies the edits people make to it, including several people at once.
- Prepares the workflow in the compact form the board understands.

## Where it fits

The studio, the hosting and the website all use it, so a workflow means the same thing everywhere.
