# Shared

`@henglosio/shared`

The common ground of Henglos IO — what the apps and packages need to agree on.

## What it does

- Describes what a package's manifest looks like.
- Defines the messages the studio, the hosting, the driver and the board exchange.
- Holds small helpers used everywhere.

## Where it fits

Almost every other app and package uses it, so they all speak the same language.
