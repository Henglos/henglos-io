# Raspberry Pi Pico

`@henglosio/board-rpi-pico` — a Henglos IO board.

The Raspberry Pi Pico (RP2040), ready to use with Henglos IO.

## What it brings

- Its pins, and what each one can do (digital, analog, PWM, UART…), so the studio only offers the right pins.
- Its firmware: the stock MicroPython, written by UF2 — the Pico's bootloader drive — with the Henglos IO platform on its filesystem.

## Getting it

Pick it when you create a workflow, or change to it from the workflow's settings. To flash it, pick its drive (RPI-RP2): a Pico that isn't in its bootloader is put there through its serial port, or hold BOOTSEL while plugging it in.
