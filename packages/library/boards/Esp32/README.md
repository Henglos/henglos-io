# ESP32

`@henglosio/board-esp32` — a Henglos IO board.

The classic ESP32 development board (ESP32_GENERIC), ready to use with Henglos IO.

## What it brings

- Its pins, and what each one can do (digital, analog, PWM, I2C…), so the studio only offers the right pins.
- Wi-Fi and Bluetooth — so components that need them, like WiFi and HTTP, can run on it.
- Its firmware: MicroPython, with the Henglos IO platform built in.

## Getting it

Pick it when you create a workflow, or change to it from the workflow's settings.
