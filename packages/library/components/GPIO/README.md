# GPIO

`@henglosio/component-gpio` — a Henglos IO component.

Turns a pin on and off, or reads whether it is on — for buttons, switches, relays, LEDs…

## What it can do

- **Write** — turns the pin on or off.
- **Read** — tells whether the pin is on or off.

## Triggers

- **Pin Trigger** — runs a branch when the pin changes — a button pressed, say.

## Getting it

Add it to a workflow from the studio's library — search for **GPIO**.
