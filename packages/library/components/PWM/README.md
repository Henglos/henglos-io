# PWM

`@henglosio/component-pwm` — a Henglos IO component.

Something in between on and off — dim a LED, set a motor's speed, drive a buzzer.

## What it can do

- **Write** — sets the level and holds it.
- **Fade** — moves smoothly to a new level over a time.
- **Stop** — turns the signal off.

> For servos, use the Servo component.

## Getting it

Add it to a workflow from the studio's library — search for **PWM**.
