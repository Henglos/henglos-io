# Time

`@henglosio/component-time` — a Henglos IO component.

Waiting, measuring time and keeping a rhythm.

## What it can do

- **Delay** — waits for a set time.
- **Uptime** — how long the board has been on.
- **Start Timer / Elapsed** — start a stopwatch and read it later.
- **Every** — runs part of a loop at a fixed pace, without holding up the rest.

## Triggers

- **Timer Trigger** — runs a branch on a schedule.

## Getting it

Add it to a workflow from the studio's library — search for **Time**.
