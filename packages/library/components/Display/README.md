# Display

`@henglosio/component-display` — a Henglos IO component.

Text, drawings and charts on a small OLED screen (SSD1306 or SH1106).

## What it can do

- **Print / Scroll** — shows text, still or scrolling.
- **Draw / Image** — draws shapes, icons or your own pictures.
- **Bar / Gauge / Chart** — shows a reading as a bar, a dial or a graph over time.
- **Clear / Settings** — blanks the screen; changes brightness, rotation and power.

## Getting it

Add it to a workflow from the studio's library — search for **Display**.
