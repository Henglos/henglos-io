# Joystick

`@henglosio/component-joystick` — a Henglos IO component.

A 2-axis joystick with a push button (KY-023 and the like).

## What it can do

- **Read** — where the stick is, and whether the button is pressed.
- **Direction** — goes Up, Down, Left, Right or Center.
- **Button** — goes one way when the button is pressed, another when it isn't.
- **Calibrate** — sets where the stick rests.

## Getting it

Add it to a workflow from the studio's library — search for **Joystick**.
