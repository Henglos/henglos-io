# DHT

`@henglosio/component-dht` — a Henglos IO component.

Temperature and humidity, from a DHT11 or DHT22 sensor.

## What it can do

- **Read** — the temperature and the humidity — plus how hot it feels and the dew point.

## Triggers

- **Climate Trigger** — runs a branch when it gets too hot, too cold, too humid or too dry.

## Getting it

Add it to a workflow from the studio's library — search for **DHT**.
