# Ultrasonic Sensor

`@henglosio/component-ultrasonicsensor` — a Henglos IO component.

Measures distance with an ultrasonic sensor like the HC-SR04.

## What it can do

- **Measure** — how far away the nearest object is.
- **Detect** — goes one way when something is close, another when it isn't.

> The HC-SR04 works at 5 V: on a 3.3 V board like the ESP32, connect its Echo pin through a voltage divider.

## Getting it

Add it to a workflow from the studio's library — search for **Ultrasonic Sensor**.
