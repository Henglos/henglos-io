# HTTP

`@henglosio/component-http` — a Henglos IO component.

Talks to the web — call an API, or answer requests that come in.

## What it can do

- **Request** — calls a web address and keeps the answer.
- **Read JSON** — picks one value out of an answer.
- **Respond** — answers a request that came in.

## Triggers

- **Request Trigger** — runs a branch when a request comes in — a webhook.

> Needs a network: use the WiFi component's Connect first.

## Getting it

Add it to a workflow from the studio's library — search for **HTTP**.
