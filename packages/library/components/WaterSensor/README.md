# Water Sensor

`@henglosio/component-watersensor` — a Henglos IO component.

Detects water — a leak under the sink, a full tank, rain.

## What it can do

- **Read** — how much of the sensor is under water.
- **Detect** — goes one way when it is wet, another when it is dry.
- **Calibrate** — teaches the sensor what "dry" and "wet" look like.

## Triggers

- **Water Trigger** — runs a branch when it gets wet, or dries off.

## Getting it

Add it to a workflow from the studio's library — search for **Water Sensor**.
