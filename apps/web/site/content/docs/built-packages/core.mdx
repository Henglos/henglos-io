Three components come with every workflow: you don't install them, and they need nothing of the
board.

| Component | Nodes |
| --- | --- |
| **Start** | The boot trigger — every workflow has one. |
| **Logic** | If, Switch, Repeat. |
| **Variables** | Set, Append, Set Field, Clear. |

## Start

The trigger that runs when the program starts. Its **Mode** decides what happens after:

- **Loop** — its branch runs again each time it reaches an action with nothing wired after it.
- **Once** — its branch runs once, at boot; from then on the board only answers the other triggers.

Start also puts the workflow's [variables](/docs/studio/variables) on the board with their initial
values. See [Triggers](/docs/studio/triggers).

## Logic

The flow's decisions. Logic nodes pass the context on by default
([Pass Context](/docs/studio/configurations#pass-context)), so what came before them still reaches
the actions after.

### If

Goes out **True** or **False**, depending on a condition — or on two, joined with **AND** / **OR**.

| Setting | What it's for |
| --- | --- |
| **Value** | What to test — a literal, or bind it to an output, a variable or a script. |
| **Condition** | How to test it: *is equal to*, *is greater than*, *contains*, *starts with*, *is true*, *is empty*… |
| **Compare to** | What Value is compared with (not shown for *is true*, *is empty*…). |
| **Combine** | *Single condition*, *AND* or *OR* — adds **Value 2**, **Condition 2** and **Compare to 2**. |

### Switch

Routes the flow by value: out the **first case** that matches, or **Default** when none does.

| Setting | What it's for |
| --- | --- |
| **Value** | What to route on. |
| **Match** | How Value is matched against each case — the If's comparisons. |
| **Case 1, 2, 3…** | Out that case when Value matches it; empty never matches. **Add case** adds more, up to 12, and **×** removes one. |

### Repeat

Runs its **Loop** branch **Times** times, then goes out **Done**. Wire the loop's last action back
into Repeat. Publishes `iteration` — 1 on the first time round.

See [Logic](/docs/studio/logic) for how they're used.

## Variables

Values shared by the whole workflow — every branch, every loop — kept on the board while it runs.

| Node | Does |
| --- | --- |
| **Set** | Stores a value in a variable — a literal, or an output, another variable or a script. |
| **Append** | Adds an item to the end of a list variable. **Max Items** keeps only the newest. |
| **Set Field** | Sets one field of an object variable — adds it if it isn't there. |
| **Clear** | Empties a list or an object variable. |

Any setting reads a variable — drag it onto the field — and a script reads it with
`ctx.var("name")`. See [Variables](/docs/studio/variables).
