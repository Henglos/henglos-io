The packages made by Henglos IO. Each page lists every node of the package — what it does, its
settings and what it publishes. Components are npm packages (`@henglosio/component-…`): install
one from the studio's component store by its name. **Start**, **Logic** and **Variables** come with
every workflow.

<WorkflowPreview name="water-alarm" height={440} />

A leak alarm made of three of them: **Water Sensor**'s Read in Start's loop, an **If** on its `wet`
output, a **GPIO** Write sounding the alarm — and a button (**GPIO**'s Pin Trigger) silencing it.

## Pins and timing

| Component | Triggers | Actions | What for |
| --- | --- | --- | --- |
| [GPIO](/docs/built-packages/gpio) | Pin Trigger | Write, Read | Read or drive one digital pin; run a branch when a pin changes. |
| [PWM](/docs/built-packages/pwm) | — | Write, Fade, Stop | Dim an LED, set a motor's speed, drive a buzzer. |
| [Servo](/docs/built-packages/servo) | — | To Angle, Rotate, Release | Positional (0–180°) and continuous-rotation servos. |
| [Time](/docs/built-packages/time) | Timer Trigger | Delay, Uptime, Start Timer, Elapsed, Every | Wait, measure, pace part of a loop; run a branch every interval. |
