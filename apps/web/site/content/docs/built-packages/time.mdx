Waits, measures and paces: delays, the board's clock, timers and intervals that run part of a loop on a fixed rhythm.

## Triggers

### Timer Trigger

Runs its branch every Interval — on its own, alongside whatever Start does.

A trigger: no input, one **Out** — the first action of its branch.

**Settings**

| Setting | Type | Default | What it's for |
| --- | --- | --- | --- |
| **Interval** | Number (from 10) | `1000` | **Required.** Time between runs, in milliseconds (10 at least). |

**Publishes**

| Output | Type | What it is |
| --- | --- | --- |
| `count` | int | How many times it fired since the program started. |

## Actions

### Delay

Waits for the given duration, then continues.

**Settings**

| Setting | Type | Default | What it's for |
| --- | --- | --- | --- |
| **Duration** | Number | `1000` | How long to wait, in Unit. |
| **Unit** | One of: Milliseconds, Seconds, Minutes | Milliseconds | Unit of Duration. |

**Publishes**

| Output | Type | What it is |
| --- | --- | --- |
| `duration` | int | The time waited, in milliseconds. |

### Uptime

Reads the board's clock — milliseconds since it started.

**Settings**

No settings.

**Publishes**

| Output | Type | What it is |
| --- | --- | --- |
| `uptime` | int | Milliseconds since the board started (wraps around after ~12 days). |

### Start Timer

Starts (or restarts) a named timer. Read it later with Elapsed.

**Settings**

| Setting | Type | Default | What it's for |
| --- | --- | --- | --- |
| **Name** | Text | `timer` | Which timer — Elapsed reads it by this same name. |

### Elapsed

How long since Start Timer started the timer with this name.

**Settings**

| Setting | Type | Default | What it's for |
| --- | --- | --- | --- |
| **Name** | Text | `timer` | The timer to read, as named in Start Timer. |

**Publishes**

| Output | Type | What it is |
| --- | --- | --- |
| `elapsed` | int | Milliseconds since the timer started. |

### Every

Goes out Due once every interval, Waiting the rest of the time — runs part of a looping program on a fixed rhythm without blocking the rest.

Ends on **Due**, **Waiting** — or **Fallback** when it can't run.

**Settings**

| Setting | Type | Default | What it's for |
| --- | --- | --- | --- |
| **Interval** | Number | `1000` | How often to go out Due, in Unit. |
| **Unit** | One of: Milliseconds, Seconds, Minutes | Milliseconds | Unit of Interval. |
| **Name** | Text | `every` | *Advanced.* Tells several Every apart — each name keeps its own rhythm. |

**Publishes**

| Output | Type | What it is |
| --- | --- | --- |
| `elapsed` | int | Milliseconds since the last time it went out Due. |
