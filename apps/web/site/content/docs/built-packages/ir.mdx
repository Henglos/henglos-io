Infrared remote control, both ways — Send a remote's code from an IR LED (to a TV, an air conditioner, another board), Receive the codes a remote sends to a receiver module (VS1838B, TSOP38238), and Match one to branch when a given button is pressed — or let a Code Trigger start a branch of its own when it is. NEC (and extended NEC) and Samsung.

## Triggers

### Code Trigger

Runs its branch when a remote's code comes in — any code, or only the one set (Protocol, Address, Command). A button on the remote starting its own part of the flow, whatever else the board is doing.

A trigger: no input, one **Out** — the first action of its branch.

**Settings**

| Setting | Type | Default | What it's for |
| --- | --- | --- | --- |
| **RX Pin** | Pin (digital in) | GPIO27 | **Required.** Board pin wired to the receiver module's OUT (also called DATA or S). |
| **Protocol** | One of: Any, NEC, Samsung | Any | The protocol it has to be — Any takes either. |
| **Address** | Text | — | The device it has to be for, hex or decimal — empty for any. |
| **Command** | Text | — | The button it has to be, hex ("0x45") or decimal — empty for any button. |
| **Repeats** | On / off | Off | *Advanced.* Whether a held button's repeats count as codes too (marked repeat) — off, a held button is one press. |

**Publishes**

| Output | Type | What it is |
| --- | --- | --- |
| `protocol` | any | The code's protocol, as text — nec or samsung. |
| `address` | int | The device it's for. |
| `command` | int | The button. |
| `code` | any | All of it as text — "nec 0x00 0x45" — what Send and Match take. |
| `repeat` | bool | Whether it's a held button's repeat (with Repeats on). |

## Actions

### Send

Sends a remote's code from an IR LED — once, or as a held button with Repeats.

**Settings**

| Setting | Type | Default | What it's for |
| --- | --- | --- | --- |
| **TX Pin** | Pin (digital out) | GPIO26 | **Required.** Board pin driving the IR LED — through a transistor for range (a pin alone lights it for a meter or so). |
| **Protocol** | One of: NEC, Samsung | NEC | How the code is sent — NEC is what most remotes use (TV boxes, LED strips, cheap kits); Samsung for Samsung TVs. |
| **Address** | Text | `0x00` | The device the code is for, as Receive shows it — hex ("0x00") or decimal. NEC takes up to 0xFFFF (extended NEC past 0xFF), Samsung up to 0xFF. |
| **Command** | Text | `0x45` | **Required.** The button, as Receive shows it — hex ("0x45") or decimal, up to 0xFF. |
| **Repeats** | Number (0 to 50) | `0` | Frames sent after the code as a held button sends them, ~108 ms apart — 0 to 50. 0 is a single press. |
| **Carrier** | Number (30 to 60) | `38` | *Advanced.* The light's blink rate, in kHz — 38 for almost every remote; 36 or 40 for a few. 30 to 60. |

### Receive

Waits for a remote's code and gives its protocol, address and command — Out with it, or Fallback when none came in time. Point a remote at the receiver and run it to learn a button's code.

**Settings**

| Setting | Type | Default | What it's for |
| --- | --- | --- | --- |
| **RX Pin** | Pin (digital in) | GPIO27 | **Required.** Board pin wired to the receiver module's OUT (also called DATA or S). |
| **Timeout** | Number (10 to 60000) | `1000` | How long it waits for a code, in ms — 10 to 60000. The flow waits meanwhile. |
| **Repeats** | On / off | Off | *Advanced.* Whether a held button's repeats count as codes too (marked repeat) — off, a held button is one press. |

**Publishes**

| Output | Type | What it is |
| --- | --- | --- |
| `protocol` | any | The code's protocol, as text — nec or samsung. |
| `address` | int | The device it's for. |
| `command` | int | The button. |
| `code` | any | All of it as text — "nec 0x00 0x45" — what Send and Match take. |
| `repeat` | bool | Whether it's a held button's repeat (with Repeats on). |

### Match

Waits for a remote's code and branches on whether it's the one set — Match, Other (another button), or Timeout. Find the button's code with Receive first.

Ends on **Match**, **Other**, **Timeout** — or **Fallback** when it can't run.

| --- | --- | --- | --- |

| **Address** | Text | — | The device it has to be for, hex or decimal — empty for any. |
| **Command** | Text | `0x45` | **Required.** The button, as Receive shows it — hex ("0x45") or decimal, up to 0xFF. |
| **Timeout** | Number (10 to 60000) | `1000` | How long it waits for a code, in ms — 10 to 60000. The flow waits meanwhile. |
| **Repeats** | On / off | Off | *Advanced.* Whether a held button's repeats count as codes too (marked repeat) — off, a held button is one press. |
