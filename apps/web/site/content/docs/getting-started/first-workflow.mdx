---

A workflow that reads a button on one pin and mirrors it on an LED on another. This is what you'll
build — click a node to see its details:

<WorkflowPreview name="button-led" />

<Steps>
<Step>

### Create it

In the **Hub**, click **New workflow**, name it, pick the **ESP32** board and the latest platform.

</Step>
<Step>

### Add the GPIO component

Install **GPIO** from the component store if it isn't in your library, then add two of its actions
to the canvas: **Read** and **Write**.

</Step>
<Step>

### Wire it

Connect **Start → Read** and **Read (Success) → Write**. On **Read**, pick the button's pin.
On **Write**, pick the LED's pin.

</Step>
<Step>

### Bind the value

Drag **Read**'s `value` output onto **Write**'s **Value** field: Write now drives the LED with
whatever Read published, instead of a fixed HIGH or LOW.

</Step>
<Step>

### Run it

Pick your driver and the board's port, then **Execute**. In loop mode the flow goes back to Start
after Write, so the LED follows the button continuously.

</Step>
</Steps>

To see what each step does, press **Debug** instead — the flow pauses after every action with its
outputs on the node. See [Running and debugging](/docs/studio/running-and-debugging).
