# Website & docs

`site`

The Henglos IO public website and its documentation.

## What it does

- Presents the project.
- Hosts the docs: concepts, how to use the studio, and how to write your own boards and components.
- Lists the official packages, each with its own page.

## Running it

From the repository root: `pnpm --filter site dev`, then open [localhost:3000](http://localhost:3000).
